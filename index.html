01 / THE IDEA

A policy the agent
can work with.

A language command says what to do. A geometric target helps the policy understand where and how to act.

When an unfamiliar instruction or a changed scene causes a VLA call to fail, repeating the same command gives the agent little control. InteractVLA opens a two-way interface: the agent steers a pretrained flow-based policy with an end-effector target, then inspects its proposed motion to refine the next action.

TEST-TIME GEOMETRIC GUIDANCE

Steer a pretrained policy through geometry.

At each tool call, the agent supplies an end-effector target G = (p*, R*, w*): a position, an orientation, and a gripper state. The VLA keeps its learned motor behavior, while guidance redirects its action generation toward that target.

During flow denoising, we estimate the clean action chunk, map its native actions to command poses, and compute a complete-pose error at each execution step. Differentiating that objective through the current action expert produces a correction to the noisy action input. The policy weights stay frozen.

mt = xt + (1 − t) vθ(xt, t; c)
A target can also be rejected. Guidance is scaled and capped relative to the native flow velocity. If target error or correction demand exceeds the compatibility tolerances, generation stops early and gives control back to the agent for replanning.
The guidance update
gt = ∇xₜ Lt(C(mt), G)
xt+Δt = sg[xt + Δt (vθ − Bt(gt))]

Bt scales and caps the correction and limits guidance to an interior time window. Each integration state is detached so gradients pass through the current expert only. For bimanual actions, pose errors are summed across effectors at a shared execution index.

Compatibility is Ct = exp[−max(rt/r0, dt/d0)]. After the first guided step, Ct < e−1 triggers early return.

SOFT-TIME TARGET ALIGNMENT

Choose when to arrive, while generating how.

A pose target does not specify its arrival time. Pulling every action step toward it can collapse the approach; fixing the last step imposes a timing choice that may not fit the motion. InteractVLA treats arrival time as a latent index in the action chunk.

Early in denoising, several compatible execution steps share the guidance. As denoising progresses, the assignment sharpens around the best-matching step. Position, orientation, and gripper state share the same temporal weights, so the policy aligns a complete interaction pose.

The soft-time objective
τ = 1 − t,   βt = t² / τ²
Lsoft = −τ² log [(1/H) ∑h exp(−βtEh)]
qh(t) = softmaxh(−βtEh)
gt = tτ ∑h qh(t) ∇xₜEh

The guide objective is Lguide = (τ/t)Lsoft. Increasing βt sharpens the temporal assignment; the tτ factor separately modulates guidance amplitude.

Look, then refine.

ACTION-INFORMED AGENTIC REFINEMENT

Make the motion proposal useful to the agent.

A success flag says little about why a motion went wrong. InteractVLA exposes the full action chunk, including the executed prefix and unexecuted continuation, alongside observation history. Calibrated camera reprojections connect predicted command poses to what the agent can see.

With visual observations and proprioception, the agent can compare the approach direction, orientation, and grasp timing, then choose the recovery that matches the problem.

A

Revise the target

If the intended interaction pose is wrong, update G and call the guided VLA again to generate a new, coherent action chunk.

B

Refine the motion

If the maneuver is already useful, adjust an approach offset, lift height, or gripper-release timing through local robot-control tools.

Turn successful interactions into reusable strategies.

Recursive self-improvement uses practice environments with distinct seeds and scene layouts. The agent consolidates effective target specifications and motion corrections, then transfers those strategies to held-out evaluation instances.
