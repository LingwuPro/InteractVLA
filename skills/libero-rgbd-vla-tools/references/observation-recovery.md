# 观测驱动的抓持、恢复与双臂协作

供会话规划读取的操作经验，适用于LIBERO及RoboDojo迁移。只借鉴文本技能；执行仍走当前环境已验证的VLA、TTG和直接控制接口，不依赖WorldScape模型、WAM权重或外部规划API。本参考没有独立评测收益。

## 先确认接口与任务要求

- 保留VLA原始语言输入。正常任务关键点交给TTG；为了观察、解除卡住、退让或重新接近的额外动作由会话直接控制。
- 读取当前任务的公开完成与失败规则，并追踪当前checkout的实际判定。特别查清是否禁止抬起、是否要求持续接触、放置顺序与最后回位。规则说明不是本episode隐藏答案，不能查询GT对象状态或内部奖励。
- 可以使用当前RGB-D、相机标定、机器人自身状态和本轮动作历史。外部技能的RGB-only限制不替代用户已允许的RGB-D协议；不能将两种输入协议的成绩混为一谈。
- 明确目标是法兰还是抓取点，核对旋转、夹爪符号与单位。LIBERO工具使用XYZW四元数；外部RoboProbe技能常用WXYZ。不得照搬其固定朝向、坐标偏移或工具参数。
- 先核对实际返回字段。夹爪命令不是实测开口，计划成功不是执行到位，末端到位不是抓取成功。超时或连接断开时先核实动作执行状态，不能假设零执行而重发。

## 抓持、支撑和释放分别确认

接近前确认目标身份、可夹实体部位及后续放置路线。夹爪应作用于实体表面；碗口中心、物体视觉中心不自动是抓取点。

闭爪后用新画面检查同一物体与夹指的相对运动。任务允许搬起时，可用一次短距离移动辅助判断持物；禁止抬起的推移任务不能套用试抬。验证后沿正常路线推进，不反复抬高来增加“信心”。

搬运时持续检查物体朝向与夹持偏移。滑移、抓错物体或身份不明时，不继续沿旧计划释放；先重新观察，必要时恢复支撑再改抓法。

放置目标针对物体落点，而非仅针对TCP。释放前检查承托面和夹指退出空间；释放后确认物体离手并留在目标处，再记录阶段完成。撤离方向由当前几何决定，不能一律向上。

## 按观察到的变化恢复

每段动作后对照请求目标、机器人实测状态和新图像。用同一相机的前后画面判断进展，结合腕部视角消除遮挡；相机自身移动导致的像素变化不能当成物体运动。

动作无效时区分：尚未执行、机器人跟踪不足、未真正接触、物体被推移、抓持丢失、目标认错。下一次只调整有证据支持的因素，避免同时改变位置、姿态和夹爪而无法判断原因。

能从已有视角核实就先观察。确需主动探测时，记录要区分的问题和预期反馈，执行短段直接控制后再看图。反复尝试不增加信息时换视角或接近方式，不能靠扩大位移继续撞同一处。

保留简短状态：最后确认执行的动作、所持物体身份、已经完成的目标、当前支撑关系、未确认项和下一检查点。不跨episode复制坐标、顺序或答案。

## 双臂协作与桌面中转

仅在当前环境确实提供双臂接口时使用。按整条取放路线分工，而非只按哪只手离物体近。通道分离、无顺序依赖时可并行；共享放置区、交叉路径、接触与释放应分段协调。

两只手分别验证抓持。一只手在支撑物体时不能当作空闲观察臂；若通过移动另一腕部相机改善视野，先确认其空闲和完整手臂通道，动作由会话直接执行。

当单臂无法完成全程，且任务允许临时放下时，选择双方可达的稳定支撑区：

1. 送出手放置并释放，确认物体稳定。
2. 送出手退出接收通道。
3. 接收手依据新观测重新定位、抓取、验证保持，再完成后续操作。

不得沿用送出手旧抓点作为接收手目标。中转不等于最终放置；禁止中途释放或要求连续接触的任务不能采用此法。

## 减少无效动作，保留必要复核

空手且通道明确时可合并位置与姿态调整；接触、携物或精细对齐时缩短执行段。不要每个子动作后归位，也不要用静态等待修复错误落点。需要沉降、流动或持续按压时才推进相应物理时间。

若任务要求最终回位，在本轮开始记录自身初始完整姿态。完成放置并确认空手后再返回；任意休息姿态不等于原位。不能通过反复归位猜测隐藏完成条件。

## RoboDojo任务级参考

下列是应结合当前官方规则使用的策略，不是固定动作脚本。

| 任务 | 借鉴要点 | 不可照搬的内容 |
|---|---|---|
| `stack_bowls` | 依据完整取放路线选择碗沿抓取侧；搬运保持正立，将夹爪到碗中心偏移计入落点；一次只添加一只 | 外部固定四元数、默认左/右抓法、未经核对的模型姿态约定 |
| `push_T` | 保持桌面支撑，通过短侧推分别修正朝向和位置；脱离接触后再转腕或撤离 | 试抬、夹住后大角度转腕，以及未确认脱离就向上撤手 |
| `imitate_sorting_sequence` | 记录实际看见的示范释放顺序与已完成前缀；漏看事件保留缺口 | 根据剩余物体补猜顺序、读取生成器答案、复用其它episode顺序 |
| `put_bottles_into_dustbin` | 逐瓶跟踪身份与落点；需要换臂时评估稳定中转 | 固定从左到右顺序、固定侧抓偏好、未验证的空中交接 |
| `press_by_number` | 区分可见完整按放周期与环境登记次数；保持歧义记录 | 外部有冲突提示的按钮顺序，或通过补按消除计数不确定性 |

## 工具接入状态

LIBERO已有`observe/vla/servo/controls`，按主skill调用。RoboDojo须以`robodojo_eval/README.md`和实际policy接口为准；当前B22 launcher不是π0.5 TTG入口。

外部的`read_skill/call_tool/robot-action-timing-tool/other-arm-observer`不是本项目已注册工具。借鉴其行为时，映射到已存在的接口；没有接口就先实现并验证，不能假装调用成功。RGB局部放大可用图像查看工具完成，不能把图像裁剪当成获得新视角。
