# 接口与评价合同

## Native12

使用 checkpoint 配套模型 config、tokenizer 和动作统计量。参考适配器为 `code/robocasa365_starvla/examples/RoboCasa365/eval/native12_policy.py`；模型为 Qwen_MMDiT，不能以其他 benchmark 的动作头替代。

| 字段 | 语义 |
| --- | --- |
| 图像 | left、right、eye_in_hand 三路 RGB |
| 原始状态 | 末端相对位置3、相对四元数4、夹爪2、底盘位置3、底盘四元数4，共16维 |
| 模型状态 | 两个四元数依原 scalar-first 合同转换 rotation6D，共20维 |
| 动作 | 末端位置3、旋转3、gripper_close1、base_motion4、control_mode1，共12维 |
| 归一化 | 配套 min/max；连续通道逆变换，夹爪与模式按原 codec 阈值解码 |

动作经原生环境 converter 执行。须区分绝对/相对、世界/基座、旋转和夹爪符号。底盘 `[forward,side,yaw,torso]` 是归一化控制量，不是实际位移；移动后重新获取位姿。

## 完整 pose soft-time

参考 H50/N10/E16：轨迹视野50、去噪10步、每次执行16步；三者不能混淆。完整位置、XYZW旋转与命令开口共享 soft-time 权重；前序命令采用25%追踪近似，当前增量完整保留。引导乘 `(1-t)/t`，canonical `t∈[0.5,0.75)` 激活，其余原生更新；参考 scale30，全部12维 RMS cap0.3。

夹爪每控制步积分0.2，采用11状态网格与平方宽度误差期望；normalized<0.5张开，否则闭合。闭合概率为 `Phi((2a-1)*t/(1-t))`，命令宽度为 `0.04*(state+1)`。直接 gripper_close=0.5 仍闭合，不是半开口。

几何近似使用当前机器人基座，未建模未来移动底盘。执行前若候选底盘动作超过原门限或进入 base 模式，应以 `moving_base_codec_unsupported` 拒绝，不能改零后冒充原生候选。参考残差门限0.10米/1.2弧度/0.04米，起点距离上限0.25米；这些是接口门限，不证明物理可行或成功。

## 机器人几何与闭环

Panda grip_site 局部 X 为夹爪闭合轴，局部 Z 为指端方向，指垫中心沿局部 Z 偏移-0.0036米。须按当前手姿变换，不能把手指关节轴直接当末端轴。空手可比较平行夹爪等价腕姿分支，但掌体占据和腕相机视角不同，持物时不可直接套用。

短段检查实际位置、旋转、两指位置、物体随动、支撑与释放。自身关节/限位可用于诊断，不查询物体真值；低净空考虑整手网格而非仅 TCP。命令目标到位与真实接触、抓持及原生 success 分别判断。

## 恢复与评价

冻结原始公开语言、完整初态、模型/噪声与预算。MuJoCo 物理状态之外，恢复 Python 几何缓存、任务引用、控制器和公开指令；相同物理哈希或 seed 不足以证明这些一致。

按原命令顺序重放保存动作，保留 dtype、实际前缀和 observe 调用节奏，不重新采样 VLA，不额外 observe。逐步核对已记录机器人状态，逐命令比较深度、相机标定、RGB 和原语言。渲染差异与物理差异分别报告；放宽渲染门限不等于逐像素复现。恢复保持原尝试与已消耗预算。

原生 success 是整例评价依据，重放一致不等于任务成功。局部控制、候选通过和直接恢复不归为纯 VLA 效果。冻结协议并用配对条件比较，不能将特权或变更语言的结果混入观测协议。
