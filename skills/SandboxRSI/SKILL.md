# SandboxRSI

本技能组织 RoboDojo 的任务策略与控制实现。先读[运行合同](references/pipeline.md)，再按[任务索引](references/task-index.md)读取具体策略；共用控制实现见[原语](references/common-primitives.md)，方法解释见[技巧](references/techniques.md)。复现接口见[复现说明](references/reproduction.md)。

## 信息与执行边界

默认以当前 RGB-D、机器人自身状态、语言及已执行动作历史决策。部分参考实现使用物体真值、内部答案或训练集检索；这些是特权沙箱分支，只有明确授权时才能启用，不能称为纯视觉或无特权评测。LIBERO 的七维 OSC 不可直接用于 RoboDojo 的双臂关节动作。

冻结 VLA 权重与采样配置；保持原生环境物理、布局、步数预算及成功谓词。先按实验协议完成原生策略基线，失败后在剩余预算内进行关键点引导或直接控制恢复。需要新 reset 时登记新尝试，不覆盖失败，不以工程恢复重置剩余预算。

只有 `success == true && benchmark_invalid == false` 计成功。夹持、局部阶段完成、几何检查或部分 score 均不能代替原生判定；终态后停止控制。策略建议不等于已经验证的跨布局成功方案。

## 闭环恢复

从最新图像确认目标身份、可见表面和运动方向；规划完整末端姿态并考虑整只手与另一只手的净空。短抬验证物体随手运动，持续检查夹爪开度及滑移；释放后撤手并重新观察支撑。跨布局不能复制绝对世界坐标，物体相对变换也须按当前抓持重测。

已保存动作的回放应恢复初态、动作类型、控制器状态以及命令和观测调用顺序，不重新采样历史 VLA。重放一致性与原生任务成功分别验证。工具调用数、仿真步数和 token 数是不同量，未测得 token 用量时不得推算成实测值。
