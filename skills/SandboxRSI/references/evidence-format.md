# 可复现记录接口

运行记录可包含初始化元数据、原始请求、实际响应、执行动作前缀及原生终态。工具请求数、VLA chunk 数和仿真控制步数分别记录；未执行候选必须标为零步，不能当作执行成功。

复现需要完整动作数组、原 dtype、初态与控制器状态、原始任务语言、环境和模型版本以及观测调用顺序。只保存 seed 不足以恢复所有任务缓存或随机状态。记录已有动作可用于无策略重采样的物理回放。

原生 `success` 与 `benchmark_invalid` 独立存储，无效 score 不强制变零。局部进展、几何判断、渲染一致性和原生任务成功应分开记录；未实际测得 token 数时不以调用数代替。
