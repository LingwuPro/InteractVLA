# 复现接口

发布代码在 `sources/campaigns/` 中保留策略控制实现与模型桥接，`sources/dependencies/` 提供几何和机器人依赖。先配置发布包路径，安装对应仿真和策略环境，再为独立运行目录提供模型、任务、初态及服务参数。

典型顺序：启动冻结策略服务；启动仿真/协议适配；用公开指令和冻结初态执行原生基线；在预算内调用观测、VLA 或直接控制；以原生判定结束。源码中的私有部署路径已改为可配置项，历史结果和动作文件不是本包运行输入。

`prepare_reproduction.py`、`run_prepared.py` 和 `inspect_episode.py` 面向外部提供的记录使用；没有对应记录时不能凭空复现历史案例。新运行目录不得覆盖原记录。SSH 认证由交互或环境配置提供，不写入代码、日志或命令参数。

动作回放需要源环境版本、完整初态、动作 dtype 和命令调用顺序。保持重放与在线策略执行分开；回放时不重新请求 VLA。新环境重建后逐步比较实际机器人状态，并单独核对原生成功。
