# 双臂控制与任务恢复方法

## 坐标、IK 与动作

原生动作为14维双臂关节目标，不能使用 LIBERO 的七维 OSC。世界 pose 为 `[x,y,z,qw,qx,qy,qz]`；SciPy 四元数顺序为 XYZW。TCP 相对 flange 沿局部 X 偏移0.145米，`p_tcp=p_flange+R@[.145,0,0]`；IK 目标反向扣除该偏移。各臂世界基座由实测末端与 URDF FK 计算，不假定共基座。

IK 使用机器人原生关节范围及连续解，分别核对位置与旋转残差。关节插值粒度的单位为每帧弧度，不是笛卡尔距离或全局速度。控制另一臂时保留静止臂上次命令目标，避免反复使用受负载下垂的实测关节角造成累积下降。

## 抓持、放置与双臂交接

预检接近、接触、抬升路径；几何原点不等于接触面中心。夹爪接口1为开、0为闭，任务代码可能使用中间开度。抓后按当前物体相对 TCP 的实测偏移与旋转规划，持续检查滑移。双臂交接须先建立接收臂抓持，再释放原臂；空间不足时使用当前可见支撑面中转。

物体相对变换可重定向，但绝对世界坐标不可跨布局复用。特权分支中的 bbox、内部答案和训练集轨迹只在授权范围内使用；观测分支需从实时传感器构造目标。

## 任务结构

堆叠时为后续物体保留净空，避免接近路径碰动已有层；排序与模仿任务需要显式任务进度，不把上次布局的顺序当作当前答案。敲击类区分工具头、接触与离开阶段，不能只追踪腕部高度。

倾倒应以真实容器唇缘构造旋转中心，并按当前抓持偏移计算腕姿；整体绕腕旋转可能使出口偏离容器。窄槽插入先确认朝向与整段可达性，再小步闭环推进。软物体折叠、液体操作和精密插入中的局部进展不构成原生成功保证。

完整方法和参数实现见[任务索引](task-index.md)与[控制原语](common-primitives.md)。算法分支存在不表示其独立因果收益已验证。
