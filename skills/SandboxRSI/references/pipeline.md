# RoboDojo 运行合同

模型服务与仿真通过显式配置的端点通信，资源分配由运行者提供。冻结模型、原生动作 codec、采样噪声和评价条件；不能因服务器迁移改动任务物理或判定。

控制循环为：恢复初态与原始任务文本 → 获取观测 → 原生 VLA → 检查实际进展 → 按授权边界构造完整 pose 或直接恢复 → 新观测 → 原生终态。所有策略与直接动作共同消耗该轮原预算；reset 是新尝试，工程回放不产生新的策略尝试。

RoboDojo 使用14维双臂关节动作；世界 pose 为位置加 WXYZ 四元数。内部目标/答案和训练集检索只用于明确授权的特权分支，必须与观测驱动协议分开报告。

完整 pose soft-time 使用同一时刻权重读取位置、朝向与夹爪误差；four_anchor 为独立结构消融。详细公式见相邻 LIBERO 技能的 TTG 参考。

保存实际动作、命令顺序及必要状态用于工程恢复。回放只执行原动作前缀，保留原 dtype、观测节奏和终止条件。只有有效的原生 success 计成功；调用次数、仿真步数和采样次数分别计量。
